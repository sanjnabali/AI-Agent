
# AI-Powered Query Agent for Material Science Research

The **AI-Powered Query Agent** project is designed to develop an advanced system that efficiently answers queries related to material science by utilizing cutting-edge techniques in **Natural Language Processing (NLP)** and **Retrieval-Augmented Generation (RAG)**. This project leverages powerful models and libraries such as **BERT**, **Gemini**, **FAISS**, and more, to enhance the accuracy and relevance of responses to material science-related queries.

## 🔍 Overview

The project utilizes an intelligent AI agent capable of answering complex material science queries by combining **retrieval-based methods** and **generative models**. Here's how the process works:

- **Data Extraction and Preprocessing**: A collection of **66 PDF documents** is utilized. Text and images are extracted and preprocessed, forming manageable chunks of data.
  
- **Indexing and Retrieval with FAISS**: The extracted data is indexed using **FAISS (Facebook AI Similarity Search)** to enable efficient and quick retrieval of relevant information based on user queries.

- **Retrieval-Augmented Generation (RAG)**: RAG combines **retrieval** with **generative models** to improve the accuracy of answers. By retrieving relevant documents and using them as context, the model generates more coherent and contextually accurate responses.

- **Query Processing with BERT**: The project uses **BERT (Bidirectional Encoder Representations from Transformers)** for initial query processing. BERT is responsible for understanding the context and semantics of user queries, enabling the retrieval of relevant text chunks.

- **Gemini Model Comparison**: A comparison is made between the **BERT** and **Gemini** models to evaluate the response accuracy and quality. This step is crucial for selecting the best model and ensuring optimal performance.

## ⚙️ Key Components and Features

- **Data Extraction**: Text and images are extracted from a set of 66 PDFs, divided into chunks for efficient retrieval and processing.
  
- **Indexing with FAISS**: FAISS is used to index the extracted data for fast similarity search and clustering of dense vectors, enabling rapid retrieval of relevant documents.

- **RAG Integration**: The combination of retrieval and generative capabilities allows the AI system to generate accurate, relevant, and contextually rich responses to user queries.

- **Model Comparison**: A detailed comparison between BERT and Gemini models is made to evaluate which model provides the most precise and effective responses.

- **Text and Image Integration**: The system not only retrieves relevant text but also integrates associated images to improve the quality and comprehensiveness of the responses.
